# 闸 D · 盲读者复述测试

> 短片不能像海报那样"一眼定生死"，所以闸 D 换成更客观的问法：**只给关键帧，让人复述故事**。
> 复述得出来 = 片子读得通；复述跑偏 = 我在自说自话。

## 做法

从成片按时间顺序抽 6 帧（**不告诉评委这是什么片子、不给任何背景**），两位评委各自独立回答四个问题：

1. 这部片子讲了什么？（两三句话复述）
2. 哪一张最不容易看懂？会误解成什么？
3. 给这片子起个名字？
4. 有没有哪一张像"放错了位置"？

两位评委：一位普通观众视角，一位纪录片剪辑师视角。互不通气。

## 结果

### 评委一（普通观众）

> "一张老图被'补'的过程——南海子在 1777 年被画全，1900 年烧断，1985 年鹿回来（或图被修），
> 最后笔停在空白处，图没画完。"

- **四个叙事节拍全中**（南海子 / 1777 / 1900 / 鹿归 / 图未竟）。
- 片名建议：《补图》或《南海子 · 补图》。
- 最不易看懂：**第 3 张（大殿正立面）**——"六个画面里唯一没有字幕、没有年份角标、没有'幕'字的一张……
  看起来像另一部片子的静帧"。
- 突兀：第 3 张最突兀；第 4 张（烧纸）与第 5 张（实景）质感反差大，但能接上。

### 评委二（纪录片剪辑）

> "一张老图被'补'又被时间打断，最后笔停在空白处。"

- 时间关系"清楚，但不是画面自己说的"——三个年代都用了同一套"纸/绢"材质，
  全靠幕标和字幕报年份；**第 3 张没有年份和幕标，是唯一的'时间洞'**。
- 信息量最低、可以删的：第 3 张（大殿正立面）；"除非它动起来，或者告诉我它在图里的位置"。
- 片名建议：《落墨》或《一张没画完的图》。
- 进阶建议：给三个年代不同的**物理质感**——1777 完全静止 + 暖灯；1900 手持晃动 + 高反差 + 褪色；
  1985 胶片颗粒；2080 干净到没有颗粒。

## 判定

**条件性通过（4/4 节拍命中）**，但有两条必须改：

| 问题 | 改法 | 是否已改 |
| --- | --- | --- |
| 第 3 张"像另一部片子"（时间洞） | 三张界画各加地点标注「图中所绘 · 璇源堂／涵道斋／翠润轩」，把"这是图上的一笔"说出来 | ✅ |
| 三个年代质感一样，靠字幕报年份 | 1900 两镜加手持微颤 + 提高反差；2080 两镜**去掉颗粒**；Act IV 年份改成「一九八五 — 今」，说清画面是今天 | ✅ |
| 幕标被读错（"四·易起""五·留守"→ 实为"四·另起""五·留白"） | 字号 32→34、字重 Light→Medium、不透明度 215→238 | ✅ |

**不改的**：片名仍用《补图》。两位评委都提到《落墨》，理由是它和五个幕名（起图/落墨/断墨/另起/留白）更齐；
但"补图"直接说出了这部片子在干什么（AI 补一张没画完的图），对不看片的评审更有效。**记在这里，留给用户拍板。**

## 复测

改完之后重新抽同样 6 帧的对应位置，人工比对：第 3 张现在有「图中所绘 · 璇源堂」，年份角标全程在线，
1900 与 2080 的质感已分开。复测帧见 `proof/gate-d/after/`。
